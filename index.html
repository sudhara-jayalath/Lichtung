    Sync & backup

    Welcome to Lichtung. To have the same pieces on your phone and your laptop, connect your private GitHub repository. You can also start writing now and connect later.

    Pieces are saved on this device first, so writing works offline. With a repository connected, they also sync to GitHub, where every saved version is kept.

    How to make an access token
    1. Open GitHub → new fine-grained token and sign in.
    2. Name it Lichtung and choose the longest expiry you're comfortable with.
    3. Under Repository access, pick Only select repositories and choose Lichtung-me.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Generate the token, copy it, and paste it above. Use the same token on your phone and your laptop.

    The token stays on this device. It can only reach Lichtung-me, nothing else in your account.

    Connected

    This repository is public, so anyone could read your pieces. Syncing stays paused until it's private: on GitHub, open the repository's Settings → General → Danger Zone → Change visibility.
    Backup

    One file with every piece and image. Use it to bring your pieces over from the Claude version of Lichtung, or to keep a copy of your own.

    On your phone

    iPhone: open this page in Safari, tap Share, then Add to Home Screen. Android: open the Chrome menu and tap Install app. On a laptop, Chrome and Edge offer Install in the address bar; Safari on a Mac has File → Add to Dock.
